# Working in this repository

## Commands

Cargo is not on the default PATH here: prefix shell commands with
`export PATH="$HOME/.cargo/bin:$PATH"`.

The full check suite, and what a change must pass before it is pushed, is in
[docs/development.md](docs/development.md). The review gates it refers to live in
[.agents/skills/code-review/](.agents/skills/code-review/SKILL.md).
